About

I build things that
hold up at scale.

I'm Abhinav — a software engineer at IBM India, working on enterprise content platforms with Adobe Experience Manager. Components, templates, Sling Models, JCR, OSGi services, workflows: the unglamorous plumbing that large digital experiences actually run on.

Outside of AEM I build backends. Not tutorials — systems with the parts people skip. JWT access and refresh tokens with rotation and blacklisting. Redis caching with real invalidation. WebSocket fan-out with SSE fallback. Async export jobs, rate limits, health and metrics endpoints, Docker Compose so it comes up in one command.

Before that I was closer to the metal. My final-year project became a published patent — a Raspberry Pi 5 crop-protection system running YOLOv8 at 93% accuracy against real animals in real fields. I still write bare-metal STM32 firmware and grind data structures, because knowing what happens below your abstraction is what makes the abstraction trustworthy.

Backend Systems · Production Architecture

Smart Device Management Platform

A production-shaped IoT backend. JWT access (15m) + refresh (7d) with rotation and a revocation blacklist. Redis caching at 15–30m TTL with invalidation on write — cached device listings return in <100ms under 1000+ concurrent requests. WebSocket heartbeat broadcast with SSE fallback, async CSV/JSON exports behind job IDs, and an hourly cron that retires devices idle past 24h. Rate limiting, security headers, health and metrics endpoints, Dockerised.
